# Schattenakte - Shadowrun Battlemap Importer

Foundry VTT (v14+) module that imports buildings generated by roomplanner. One file per
building becomes one scene with a level per floor: floor images, walls, doors (locked ones
locked), windows (see-through, openable), lights, and stairs and elevators that move tokens
between floors (Change Level regions).

## Install

In Foundry: *Add-on Modules → Install Module*, paste the manifest URL into the field at
the bottom and install:

```
https://github.com/<owner>/<repo>/releases/latest/download/module.json
```

Then enable *Schattenakte* in your world (*Game Settings → Manage Modules*).

Without a manifest URL: unpack `schattenakte.zip` from a release into
`<Foundry Data>/modules/schattenakte/` and restart Foundry.

## Import a building

1. Get a `.schattenakte.json`: the **Foundry** button in the roomplanner UI, or
   `roomplanner generate … -f foundry`.
2. In Foundry (as GM), open the **Scenes** sidebar and click **Import building**.
3. Pick the file. The images are uploaded to `Data/schattenakte/<name>/`, the scene is
   created and opened. Importing the same building again asks to replace it.
