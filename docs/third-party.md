# Third-party data

## OpenStreetMap corridor shapes (ODbL)

`src/roomplanner/data/osm_corridors.yaml` is generated by `tools/osm_corridors.py` from
OpenStreetMap indoor mapping (`indoor=corridor` areas inside office, university, school,
hospital, commercial, hotel, government, industrial and apartment buildings). The `source`
field of every shape lists the OSM way ids it came from.

- Data © OpenStreetMap contributors, available under the Open Database License 1.0
  (<https://opendatacommons.org/licenses/odbl/1-0/>, <https://www.openstreetmap.org/copyright>).
- **The YAML file is a Derived Database** of OSM data: keep the attribution header, and any
  adapted version of it stays under the ODbL (share-alike), with its source stated.
- **Generated maps are Produced Works** if they use the `partition_osm` layout. The ODbL does
  not make them share-alike, but it requires a credit: "Corridor shapes © OpenStreetMap
  contributors (ODbL)", with a link to <https://www.openstreetmap.org/copyright>. The CLI
  prints this notice when that layout is used; put it on published maps, VTT modules and
  anything else you share. The project's own source code is not covered by the ODbL, because
  the data is loaded at run time and not part of the code.
- Refreshing the data: `python tools/osm_corridors.py fetch <dir>`, then `build <dir>`. The
  fetch goes to the public Overpass API; mind its usage policy (the tool pauses between
  requests and skips what it has already downloaded).

This note is a summary, not legal advice; the licence text governs.
